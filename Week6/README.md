# Week 6 – Generative AI Evaluation

## 1. Project Overview
This project evaluates responses generated by the local **Llama 3.2** model using Ollama.

It compares AI-generated answers with predefined expected answers using keyword overlap and calculates an evaluation score.

## 2. Technologies Used
- Python
- Ollama
- Llama 3.2
- JSON
- CSV

## 3. Project Structure

```text
Week6_GenAI_Project/
│
├── main.py
├── golden_set.json
├── baseline_results.csv
├── requirements.txt
└── README.md
```

## 4. Requirements
- Python 3.8 or later
- Ollama installed
- Llama 3.2 model

## 5. Installation and Setup

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
```

### Step 2: Navigate to the Project Folder

```bash
cd Week6_GenAI_Project
```

### Step 3: Create a Virtual Environment

```bash
python -m venv Lab
```

### Step 4: Activate the Virtual Environment

**Windows:**
```bash
Lab\Scripts\activate
```

**Linux / macOS:**
```bash
source Lab/bin/activate
```

### Step 5: Install Requirements

```bash
pip install -r requirements.txt
```

### Step 6: Download the Llama 3.2 Model

```bash
ollama pull llama3.2
```

### Step 7: Verify Ollama Installation

```bash
ollama --version
```

## 6. Run the Project

Execute the following command:

```bash
python main.py
```
